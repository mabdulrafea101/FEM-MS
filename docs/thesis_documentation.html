Core Free Vibration Equations

Eq. 1: Fundamental Concept
f_n = (1/2π) × √(k/m)

Source: Clough & Penzien (2003)

Frequency depends on stiffness (k) and mass (m). Damage reduces stiffness → frequency drops.

Eq. 2: Euler-Bernoulli
f_n = (λ_n²/2πL²)√(EI/ρA)

Source: Chopra (2012)

λ₁ = 4.730 for fixed-fixed, Mode 1. Valid for L/h > 10.

Eq. 10: FEM Core
[K]{u} = ω²[M]{u}

Source: Bathe (2014)

Generalized eigenvalue problem solved by scipy.linalg.eigh

The Two Fundamental Matrices [K] and [M]

Where do they come from? These matrices are derived from energy principles in standard FEM textbooks (Zienkiewicz & Taylor, 2000; Bathe, 2014).

Eq. 13: Stiffness Matrix [k]e
[k]e = (EI/Le³) × | 12 6Le -12 6Le | | 6Le 4Le² -6Le 2Le² | |-12 -6Le 12 -6Le | | 6Le 2Le² -6Le 4Le² |

Derived from: Strain energy U = (EI/2)∫(d²v/dx²)²dx

DOF per element: [v₁, θ₁, v₂, θ₂]

Eq. 14: Mass Matrix [m]e
[m]e = (ρALe/420) × | 156 22Le 54 -13Le | |22Le 4Le² 13Le -3Le² | | 54 13Le 156 -22Le | |-13Le -3Le² -22Le 4Le² |

Derived from: Kinetic energy T = (ρA/2)∫v̇²dx

Why 420? Hermite function integration gives this denominator

Why These Specific Numbers? (12, 156, 420, etc.)

These coefficients come from integrating Hermite cubic shape functions. The factor 1/420 in the mass matrix is the least common multiple that makes all matrix entries integers. This is NOT arbitrary—it comes directly from analytical integration of the shape functions.

Material Properties: Eq. 3 (ACI 318-19)

Elastic Modulus Formula
E_c = 4700 × √f'_c (MPa)

Source: ACI Committee 318 (2019)

  • E_c = Elastic modulus of concrete
  • f'_c = Compressive strength (25-50 MPa)
Why ACI Over Eurocode?
  • More extensively validated for 25-50 MPa range
  • Differences from Eurocode typically < 5%
  • Reference: MacGregor & Wight (2012)
  • Same approach used by Das (2023) seed paper
Also Needed: Moment of Inertia (Eq. 12)
I = bh³/12 (m⁴)

For rectangular cross-section: I depends on depth h cubed (very sensitive to depth!)

Damage Modeling Equations

I_corroded = I_original × (1 - α) [Eq. 15] α = min(1.6 × C/100, 0.9) [Eq. 16]

Source: Rodriguez et al. (1997), Cairns et al. (2005)

  • C = Corrosion level (0-100%)
  • Factor 1.6 = Amplification from Rodriguez et al. (1997) experimental work
  • Upper limit 0.9 = From Cairns et al. (2005)
Why 1.6? Stiffness loss exceeds simple steel area reduction because of bond deterioration, concrete cracking, and non-uniform section loss. Experiments showed loss ≈ 1.5-1.7× corrosion percentage.

I_effective(x) = I_original × (1 - β) if |x - x_c| ≤ w/2 = I_original otherwise

Source: Dimarogonas (1996), Chondros et al. (1998)

  • β = Crack severity (0 to 1)
  • x_c = Crack location along beam
  • w = Width of cracked zone

Key Insight: Only elements near crack location are affected. Global frequency sensitive to total stiffness loss.

Key Class: BeamFEM
class BeamFEM:
    """
    Main FEM class implementing Euler-Bernoulli beam theory.

    Equations Implemented:
    - Eq. 10: [K]{u} = ω²[M]{u} (Generalized eigenvalue problem)
    - Eq. 13: Element stiffness matrix [k]e
    - Eq. 14: Element mass matrix [m]e
    - Eq. 15, 16: Corrosion damage model
    - Eq. 17: Crack damage model
    """

    def __init__(self, L, b, h, fc, damage_type='none', damage_params=None):
        self.L = L
        self.b = b
        self.h = h
        self.fc = fc

        # Material properties (ACI 318-19 - Eq. 3)
        self.E = 4700 * np.sqrt(self.fc) * 1e6  # Pa

        # Section properties
        self.I = b * h**3 / 12  # Moment of inertia (Eq. 12)
        self.A = b * h          # Cross-sectional area
        self.rho = 2400         # Concrete density (kg/m³)
Element Stiffness Matrix Implementation
def _element_matrices(self, elem_idx):
    """Compute element stiffness and mass matrices (Eq. 13, 14)."""
    le = self.element_lengths[elem_idx]
    I_elem = self.I_profile[elem_idx]

    # Element stiffness matrix (Eq. 13)
    k_factor = (self.E * I_elem) / (le**3)
    k = k_factor * np.array([
        [12,      6*le,    -12,      6*le   ],
        [6*le,    4*le**2, -6*le,    2*le**2],
        [-12,    -6*le,     12,     -6*le   ],
        [6*le,    2*le**2, -6*le,    4*le**2]
    ])

    # Element mass matrix (Eq. 14)
    m_factor = (self.rho * self.A * le) / 420
    m = m_factor * np.array([
        [156,     22*le,    54,     -13*le  ],
        [22*le,   4*le**2,  13*le,  -3*le**2],
        [54,      13*le,    156,    -22*le  ],
        [-13*le, -3*le**2, -22*le,   4*le**2]
    ])

    return k, m
Eigenvalue Problem Solution
def solve_eigenvalues(self):
    """Solve [K]{u} = ω²[M]{u} for natural frequencies."""
    K, M = self.assemble_global_matrices()
    K_red, M_red, free_dof = self.apply_boundary_conditions(K, M)

    # Solve using scipy
    eigenvalues, eigenvectors = scipy.linalg.eigh(K_red, M_red)

    # Convert to frequencies (Eq. 11: f = ω/2π)
    frequencies = np.sqrt(eigenvalues) / (2 * np.pi)

    return Result(frequencies=frequencies, mode_shapes=eigenvectors)

Model Evaluation Function
def evaluate_model(name, model, X_tr, y_tr, X_te, y_te):
    """Train and evaluate a model with comprehensive metrics."""

    # Train model
    model.fit(X_train_data, y_tr)

    # Predictions
    y_test_pred = model.predict(X_test_data)

    # Calculate metrics
    test_mae = mean_absolute_error(y_te, y_test_pred)
    test_rmse = np.sqrt(mean_squared_error(y_te, y_test_pred))
    test_r2 = r2_score(y_te, y_test_pred)

    # Cross-validation
    cv_scores = cross_val_score(model, X_train_data, y_tr, cv=5, scoring='r2')

    return model, y_test_pred
